## About KindlyJAR

KindlyJAR merupakan web charity dengan sistem menyumbang lewat 
karya atau skill, sehingga dapat memfasilitasi pengguna dengan rasa 
sosial dan filantropi yang tinggi untuk tetap memberi bermodalkan 
keahlian mereka tanpa perlu mengeluarkan uang.

Nama KindlyJAR merupakan gabungan dari kata “Kindly” (kebaikan atau dengan 
baik hati) dan “JAR” (toples atau wadah). Nama ini memiliki filososi dan arti 
sebagai sebuah “wadah pengumpul kebaikan”. Layaknya sebuah toples yang 
diisi koin demi koin untuk ditabung. KindlyJAR menjadi wadah digital tempat 
terkumpulnya hasil kerja keras dari para HERO(penjual) yang didedikasikan 
sepenuhnya untuk membantu sesama.
